# БЮРО НАХОДОК — МБОУ СОШ №2

Публичный сайт без регистрации для посетителей. Публикации автоматически поступают из отдельной группы Telegram через Telegram Bot API.

## Возможности

- Адаптивный сайт для компьютера и телефона.
- Карточки публикаций с фото, описанием, датой и категорией.
- Поиск по тексту и фильтр категорий.
- Автоматическое обновление ленты (проверка раз в 30 секунд).
- Фото и текстовые сообщения из Telegram.
- Закрытая паролем панель `/admin`: отметить вещь возвращённой или удалить публикацию.
- SQLite и постоянный диск Render для хранения данных и фотографий.

## 1. Создайте Telegram-бота

1. В Telegram откройте `@BotFather`, отправьте `/newbot` и выполните инструкции.
2. Сохраните токен бота. Не отправляйте его посторонним и не вставляйте в публичный код.
3. Добавьте бота в отдельную группу «Бюро находок».
4. В `@BotFather` выполните `/setprivacy` → выберите бота → `Disable`. Это нужно, чтобы бот видел обычные сообщения группы, а не только команды. Если бот назначен администратором группы, проверьте, что у него есть право видеть сообщения.
5. Проверьте, что в группе нет личных данных учеников, адресов, телефонов и других чувствительных сведений. Публикуйте только необходимые сведения о вещи.

Бот обрабатывает обычные сообщения и подписи к фото. Не публикуйте в группу пароли, документы с персональными данными или фотографии людей без разрешения.

## 2. Разместите проект на GitHub

1. Распакуйте архив.
2. Создайте новый приватный или публичный репозиторий GitHub (секретов в проекте нет).
3. Загрузите содержимое папки проекта в корень репозитория.

## 3. Разверните на Render

Самый простой вариант — Blueprint:
1. В Render выберите **New → Blueprint**.
2. Подключите GitHub и выберите репозиторий с `render.yaml`.
3. Подтвердите создание сервиса.
4. В Environment заполните:
   - `TELEGRAM_BOT_TOKEN` — токен от BotFather.
   - `ADMIN_PASSWORD` — придумайте длинный пароль для панели.
   - `SITE_URL` — полный адрес сервиса, например `https://buro-nahodok-school2.onrender.com` (без `/` в конце).
   - `PUBLIC_CONTACT` — как посетителю связаться с ответственным сотрудником.
5. Сохраните переменные и дождитесь успешного Deploy.

`TELEGRAM_WEBHOOK_SECRET`, `SETUP_KEY`, `FLASK_SECRET_KEY`, `DATA_DIR` и `UPLOAD_DIR` создаются/задаются Blueprint автоматически.

**Важно:** для постоянного хранения SQLite и фотографий нужен подключённый Render Persistent Disk. Он уже описан в `render.yaml`. Постоянные диски могут быть доступны не на всех тарифах Render; проверьте доступность и стоимость до публикации. Без диска файлы и база могут пропасть при перезапуске или новом развёртывании.

## 4. Подключите Telegram к сайту

После первого успешного Deploy:
1. Откройте в браузере адрес (замените домен и значение ключа):

   `https://ВАШ-САЙТ.onrender.com/setup-webhook?key=ВАШ_SET​UP_KEY`

2. Возвращённый ответ Telegram должен содержать `"ok": true`.
3. Отправьте тестовое сообщение в группу. Через несколько секунд оно появится на сайте.

Ключ `SETUP_KEY` можно посмотреть в Environment на Render. Не пересылайте эту ссылку другим: она позволяет менять webhook бота.

Если Telegram не присылает сообщения, проверьте: бот добавлен в нужную группу; Privacy Mode выключен или бот администратор; токен и webhook secret заданы; webhook зарегистрирован на адрес вашего сайта.

## 5. Панель управления

Откройте `https://ВАШ-САЙТ.onrender.com/admin` и войдите с `ADMIN_PASSWORD`.
Можно:
- отметить публикацию как «Владелец найден» (она останется в ленте с отметкой);
- вернуть публикацию в обычную ленту;
- удалить ошибочную публикацию.

Посетителям пароль не нужен. Админ-панель не отображается в публичной навигации.

## Локальный запуск на Windows

Требуется Python 3.10+.

```powershell
py -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
```

Заполните `.env`, затем:

```powershell
python app.py
```

Откройте `http://127.0.0.1:5000`. Для локального теста Telegram webhook нужен публичный HTTPS-адрес (например, временный туннель); проще сначала развернуть приложение на Render.

## Категории

Категория определяется автоматически по ключевым словам в тексте сообщения. Если подходящее слово не найдено, публикация попадает в «Другое». Текст сообщения целиком сохраняется в описании.

## Примечания

- Сайт публичный: любое сообщение, отправленное в подключённую группу, может стать публичной публикацией. Используйте отдельную группу только для проверенных объявлений.
- Бот получает только те сообщения, которые Telegram разрешает ему видеть. Сообщения, отправленные до добавления бота, не импортируются.
- Текстовые сообщения без фото также публикуются.
- В текущей версии изображения Telegram поддерживают JPG, PNG и WEBP. Максимальный размер входящего HTTP-запроса сайта — 12 МБ.
- Для безопасности используйте отдельный бот и отдельную группу, не давайте доступ к панели посторонним.
